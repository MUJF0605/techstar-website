# 模块拆解

## 管线数据流
PNG/JPG 输入
  → 预处理（Alpha 阈值截断）
  → 色彩聚类（LAB K-means + CIEDE2000）
  → 区域合并（最小面积过滤）
  → 矢量化（vtracer 按色层调用）
  → 边缘清理（路径简化）
  → PSD 组装（ag-psd：矢量智能对象 + 白墨层）
  → 输出 PSD

## 模块清单
1. 输入解析模块
2. 预处理模块（Alpha 处理、背景剥离）
3. 色彩聚类模块
4. 区域合并模块
5. 矢量化模块（vtracer 封装）
6. 边缘清理模块
7. 白墨生成模块
8. PSD 组装模块（ag-psd 封装）
9. 管线编排模块
